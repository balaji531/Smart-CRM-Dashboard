## 📌 Overview

Smart CRM Dashboard is a full-stack web application designed to manage customers, products, and sales operations efficiently.  
It provides real-time revenue tracking, performance analytics, and interactive dashboards to support data-driven decision-making.

---

## ✨ Key Features

- 👥 Customer Management  
- 📦 Product Inventory Tracking  
- 💰 Sales Recording & Monitoring  
- 📊 Revenue Analytics  
- 📈 Interactive Chart.js Dashboards  
- 📱 Fully Responsive UI  

---

## 🛠 Tech Stack

| Layer        | Technology Used |
|-------------|-----------------|
| Frontend    | HTML, Tailwind CSS, JavaScript |
| Backend     | Python (Flask) |
| Database    | MySQL (XAMPP) |
| Visualization | Chart.js |

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/balaji531/Smart-CRM-Dashboard.git
cd Smart-CRM-Dashboard
```
---

### 2️⃣ Create Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate
```
---

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```
---

---

## 4️⃣ Configure Database

- Start XAMPP  
- Create MySQL database named as crmdb
- Import SQL file (schema.sql)
- Update database credentials in your backend file
---

### 5️⃣ Run the Application

```bash
python app.py
```
Open in browser:
```bash
http://127.0.0.1:5000
```
